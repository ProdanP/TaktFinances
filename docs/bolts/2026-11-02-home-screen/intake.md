# Intake

## Depth

feature

## Summary

This bolt adds a Home feature UI that opens when Continue is tapped on Landing. Home hosts three empty mock tabs—Dashboard, My Finances, and Profile—inside one `:feature:home` module. Compose lives in `:sharedUI` for Android and desktop; SwiftUI lives in `iosApp`. Navigation chrome adapts by form factor: bottom bar on phones, NavigationRail or a drawer on tablets, foldables, and large windows.
