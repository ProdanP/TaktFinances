# System

Living description of this project. When a change alters behavior, fold a short delta in here.

Kotlin Multiplatform app for Android, desktop, and iOS. Shared business rules live in feature modules. Android and desktop UI is Compose in `:sharedUI`. iOS UI is SwiftUI in `iosApp`. Module boundaries, layer rules, and the patterns to use are in [architecture.md](architecture.md). Screen state is in [presentation.md](presentation.md). Phone, tablet, and foldable layouts are in [adaptive-ui.md](adaptive-ui.md). Domain packages (entities, errors, use cases, repository interfaces) are in [domain.md](domain.md). Repositories, SQL, and HTTP are in [data-access.md](data-access.md). Recoverable failures are in [errors.md](errors.md). Allowed libraries are in [stack.md](stack.md). Screen designs are in the Figma file named in [figma.md](figma.md).

The app opens on the onboarding Landing screen. Domain lives in `:feature:onboarding`. Continue opens Home. Home domain lives in `:feature:home` with Dashboard, My Finances, and Profile mocks. Android and desktop share Compose in `:sharedUI` (`com.prodan.taktfinances.onboarding` and `.home`); chrome follows `WindowWidthSizeClass` (bar / rail / permanent drawer). iOS uses SwiftUI in `iosApp/iosApp/Onboarding/` and `Home/`; chrome follows `horizontalSizeClass` (TabView / NavigationSplitView).

Accounts are tracked by periods. Bank and Loan accounts are Monthly: each month holds at most one check-in, a missing month carries the previous balance forward, and the current balance is the current month's month-end balance. Investment accounts are tracked by trades and start at 0.00 until trades exist. The rules (`monthEndBalances`, `checkInMonths`, `CheckInUseCase`, `DeleteCheckInUseCase`) live in `:feature:accounts` domain; storage is `finance_account`, `account_period` and `monthly_entry` in the one Room database (version 2, rebuilt empty from older versions while unreleased). My Finances cards open Account Detail (header, 6M/1Y/All balance chart, monthly timeline, check-in sheet) on Android, desktop (`accounts/AccountDetail*` in `:sharedUI`) and iOS (`iosApp/iosApp/Accounts/AccountDetail*`).

The color export in `docs/system/material-theme.json` drives the theme: Material 3 Expressive tonal spot (Material Color Utilities, 2025 color spec) from seed `#1C6873`, teal with a pale blue tertiary. Android and desktop share the Material 3 color schemes in `:sharedUI` under `MaterialExpressiveTheme`, which also brings expressive motion and component defaults. Android also follows the system contrast preference. Desktop uses the standard scheme for the system appearance. iOS uses the same roles as semantic colors, keeps the system font, and uses the high scheme when contrast is increased.
