# Intent

Write `intent.md` from this skill's `assets/intent.md` when the file does not exist yet.

Required headings, each on its own line:

- `## Problem`
- `## Done when` — concrete outcomes, one per line

Ask only questions that would change the done-when list. Then write the file.

Stop after the artifact is written. Do not run `advance` in this turn. The router leaves this stage only after `approve intent`.
